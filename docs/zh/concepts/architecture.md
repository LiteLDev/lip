# 架构

`lip` 用于管理工作区中已安装包的状态。

## 工作区状态

表示工作区当前状态，追踪安装了哪些包以及安装方式。
- **Packages**：已安装包集合。
- **Manifest**：当前项目的清单文件（如果存在）。

## 配置

用于管理 `lip` 工具本身的全局配置（如代理和默认行为）。
- **Properties**：配置项键值对（例如 `github_proxy`）。

## 包来源

包通过 HTTPS 直接从其 git 仓库解析和下载，使用 lip 内置的 git smart-HTTP（协议第 2 版）客户端；无需安装 `git` 命令行工具。
- **注册表**：从 `v<semver>` 标签列出包的版本，并在不下载其他文件的情况下读取标签处的 `tooth.json`。
- **来源**：提供标签提交的文件列表，并按需下载文件内容，只下载清单放置规则选中的文件。
- **缓存**：按 git 对象 ID 存储下载的文件，在不同版本和不同包之间共享。

详见[内部机制](../guides/internal_mechanism.md#包解析)。
