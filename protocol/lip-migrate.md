# lip-migrate(1)

## NAME

lip-migrate - migrate `tooth.json` to `lip.toml`

## SYNOPSIS

```
lip migrate [-h | --help]
```

## DESCRIPTION

`lip migrate` migrates the current working directory as [lip-compatibility(7), "lip migrate"](lip-compatibility.md#lip-migrate) defines.
