# lip-cache(1)

## NAME

lip-cache - delete the cache

## SYNOPSIS

```
lip cache clean [-h | --help]
```

## DESCRIPTION

`lip cache clean` deletes the cache directory ([lip-userspace(7)](lip-userspace.md)). Workspaces and the configuration are not affected.
